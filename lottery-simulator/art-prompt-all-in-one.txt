I'm making art for a browser game called "Lottery Simulator". Please create every image listed below, following the style guide exactly. Make them one at a time in the order listed (T1 first). After each image, tell me which asset ID you just made and which one is next, then continue when I say "next".

=== THE GAME ===
The player sits in front of a slot machine in a busy casino. Each tap buys a $1 ticket. Almost every time the machine shows a huge red "FAIL". Rarely it pays out and shows a happy monkey. There are 5 collectible monkeys; one, a grinning black crested macaque, is rare.

=== CAMERA AND LAYOUT ===
First-person view: we are seated on a stool facing a slot machine. The slot machine cabinet fills the middle of the screen and most of its height. Its glass screen is where the game happens. The casino floor stretches out behind and around the machine: rows of other slot machines, card tables, chandeliers, neon signs, red patterned carpet and patrons seen as silhouettes. Wide 16:9 framing.

=== ART STYLE (applies to every image) ===
- 16-bit console pixel art, like a mid-1990s SNES / Sega Genesis game.
- Native resolution of 384x216 pixels, scaled up with hard nearest-neighbour edges so every pixel is a crisp square block. No anti-aliasing, no blur, no smooth gradients (dithering only), no painterly texture.
- Limited palette, about 32 colours per image. Dark outlines (deep purple or near-black, not pure black) around objects.
- Light comes from the slot machine and neon signs: warm gold and red highlights, deep purple and navy shadows.
- Palette anchors: casino carpet deep red #7A1028 with gold #FFCF33 pattern; walls and shadows navy #141433 and purple #2A1A4A; chrome #C8D0E0 to #6A7090; neon pink #FF4FA8 and cyan #3FE0FF; jackpot gold #FFCF33; FAIL red #FF2424; money green #63D47F.
- Fun and cartoony, not seedy. No real casino names, logos or brands. No readable text unless an asset asks for it, and any requested text must be spelled exactly as written.

=== SPRITE SHEET RULES (for every animation) ===
Draw all frames in one image as a single horizontal row, left to right, every frame the same size, evenly spaced, with the object in the same position in each frame so the frames line up. Transparent background (or flat #FF00FF magenta if transparency isn't possible). No frame numbers, borders or labels.
